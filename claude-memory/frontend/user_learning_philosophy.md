name: user_learning_philosophy
description: Felix's core philosophy for interactive skills — guided/unguided learning, anti-decision-fatigue, information density limits
type: user
---

Felix values interactive, checkpoint-based skills that sharpen the developer's mind rather than replace it. Key principles:

- **Guided + unguided learning**: Walk through concepts step-by-step, then surface targeted challenges only when gaps are observed in the developer's thinking. Never random quiz questions.
- **Information density**: Never present a wall of text. Split each checkpoint into multiple small passes — ONE concept per message, then pause for discussion.
- **Brain-on mode**: Keep the developer actively reasoning (predict, explain, spot the flaw) rather than passively consuming.
- **Success metric**: The developer can explain the material themselves, not that the artifact was produced.
- **Anti-decision-fatigue**: Present one thing at a time, build on prior understanding.
